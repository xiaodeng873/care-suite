## 執行摘要

本次為刪除前一次錯誤匯入後，使用修正版 `findPatient` 邏輯重新匯入的結果。

**前次問題：** `findPatient` 使用「同名唯一」與「床號互相包含」fallback，導致：
- C 區（202–237 房）部分處方錯掛到已退住、舊 `station_id=null` 的同名院友，瀏覽器因此看不到。

**修正後：** 只配對 `在住狀態=在住` 且床號（去掉前綴後）完全吻合的院友。
