# 理遺記錄每週用量預測與申請概念陳述書

## 1. 背景

- 院友每日嘅換S片記錄（床頭記錄）已記錄實際**尿片**同**片芯**使用量。
- 而家理遺記錄嘅「每週數量」靠人手估算輸入，冇同實際換片記錄連動，採購申請靠人手加總同換算包數，費時兼易錯。

## 2. 概念概述

將換片記錄嘅實際使用量**每週自動匯入理遺記錄**，用上一週實際用量**預測下一週**嘅同等用量，並按固定換算率（尿片 10 片/包、片芯 20 片/包）轉成**包數**，直接作為向倉務部申請下週物資嘅依據。

```
換片記錄（每日實際用量）
    │ 每週自動匯總
    ▼
理遺記錄：院友每週用量子列
    │ 預測下週 = 本週實際
    ▼
總數（片）→ 換算包數（尿片 ÷10、片芯 ÷20）
    │
    ▼
申請單 → 倉務部（下週物資）
```

## 3. 功能需求

### 3.1 每週自動匯總

- 系統按週（暫定**週一至週日**）將每名院友嘅換片記錄加總：尿片總數、片芯總數。
- 匯總結果寫入理遺記錄，成為該院友該週嘅用量子列，**毋須人手輸入**。
- 冇換片記錄嘅院友/週份唔生成子列（或標記為無記錄）。

### 3.2 下週預測

- 預測規則（初版）：**下週預測用量 = 最近一週實際用量**。
- 日後可擴充（見第 6 節待定問題）：移動平均、按缺席日數調整等。

### 3.3 理遺記錄主表格

- 每名院友一列**摺疊列**（父列）。
- 展開後顯示**子列**：每一週一行，列出該週尿片用量、片芯用量。
- 父列顯示彙總：總數（片）+ 換算後**包數**。
- 表格底部（或篩選後）顯示**全部院友合計**：尿片總片數 → 尿片總包數、片芯總片數 → 片芯總包數，作為申請量。

### 3.4 包數換算

| 物品 | 換算率 | 例子 |
|---|---|---|
| 尿片 | 1 包 = 10 片 | 137 片 → 14 包（無條件進位） |
| 片芯 | 1 包 = 20 片 | 86 片 → 5 包（無條件進位） |

- 包數一律**無條件進位**（寧多勿缺）。
- 換算率做入**院舍設定**，預設 10 / 20，可因應供應商改動。

### 3.5 申請倉務部

- 按預測包數產生**下週申請**。
- 申請量 = 預測包數（可加人手調整欄，調整後以人手為準）。
- 輸出形式：暫定可列印/匯出 Excel 嘅申請單（格式待定）。

## 4. 權限

- 理遺記錄維持**只限主管/開發者**（沿用現有 `adminOnly` 安排）。
- 換片記錄錄入維持護理員可用；自動匯總由系統執行。

## 5. 數據同現有功能嘅關係

- 換片記錄（`diaper_change_records`）：數據來源，唔改動錄入流程。
- 理遺記錄（`diaper_usage_records`）：由「人手估算 + 虛擬生成」擴充為「**實際每週用量自動匯入**」；現有每週估算欄位保留（人手估算同虛擬生成用途不變）。
- 新舊數據要分清楚來源：**實際**（自動匯入）vs **估算/生成**（現有功能）。

## 6. 待定問題

1. **週定義**：週一至週日定週日至週六？（建議週一至週日）
2. **預測演算法**：初版用「最近一週 = 下週」；會唔會好快要移動平均（如近 4 週）？
3. **缺席調整**：院友入院/渡假嗰週用量會偏低，預測使唔使用返佢平時嗰週？
4. **申請單格式**：倉務部有冇既定表格？需要簽署欄嗎？
5. **緩衝存量**：申請量使唔使加成（例如 +10% 安全庫存）？
6. **自動時機**：每週幾點自動匯總（例：逢週一 00:05 總結上週）？
